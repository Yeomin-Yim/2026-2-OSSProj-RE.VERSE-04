# 최종 목표

**중간발표자료와 프로토타입 HTML의 모든 기능이 실제 데이터로 동작하고, 외형은 프로토타입과 같으며, 그 위에 학생이 실제로 쓰고 싶어질 편의성을 더한 RE:Cord.**

목표는 두 단계다. 1단계를 다 채워도 멈추지 않고 2단계로 넘어가 계속 개선한다. 루프는 사람이 STOP 할 때까지 돈다.

판단 기준
- **신뢰도**: SW 개발자가 코드를 읽었을 때 납득한다. 선택의 이유가 DECISIONS.md에 있고, 테스트·타입·빌드가 통과하고, 화면에 보이는 건 실제로 동작한다.
- **UX/UI**: 프로토타입의 시각 언어를 지키고, 학생이 매 화면에서 "지금 뭘 보고 있고 다음에 뭘 하면 되는지" 안다. 빈 상태·로딩·실패 상태까지 설계돼 있다.

## 1단계 — 발표·프로토타입 기능 전부 (기능 동등)

### 공통
- [ ] 셸: 사이드바(프로젝트 관리·연결 그래프·스크랩·포트폴리오), 탑바, **전역 검색**(프로젝트·기록·문장·노트), 사용자 메뉴, 토스트, 확인 모달
- [ ] 로그인 · **회원가입** · 로그아웃, 사용자별 데이터 분리(RLS)
- [ ] PC·모바일(390px) 반응형

### ① 프로젝트 관리 (발표 p15, 프로토타입 `#/projects`)
- [ ] 프로젝트 목록·생성·수정, 상세 탭(기록 목록 / 개요 / 파일 / 연결 노트 / 결과)
- [ ] 기록 추가(직접 작성), 기록 상세(문장·태그·버전), 기록 수정 시 새 버전, 노트 이동
- [ ] **파일 올리기**(PDF·DOCX·사진) → 텍스트 추출 → 문장·태그, 사진은 증빙
- [ ] **거캠 회고록 가져오기**: 업로드 → 진행률 → 프로젝트 묶기 미리보기(제목 고치기·노트 옮기기) → 미분류 → 저장
- [ ] 저장 직후 규칙 태그 + 근거 문장 표시, **태그 고치기**(추가·삭제, 학생 수정 우선)
- [ ] 기록 확인 7항목 + 빈 항목 보완 질문(최대 2개), 답하면 메모 기록으로 저장
- [ ] ✦ AI 개요 6항목: 버튼 → 근거 문장 ID 검증 → 버전별 저장(재호출 없음) → 학생 수정

### ② 연결 그래프 (발표 p17·p22, 프로토타입 `#/learning`)
- [ ] 프로젝트 노드·간선(IDF 가중 자카드 ≥ 0.18, 굵기=유사도), 간선 클릭 시 공통 태그·양쪽 근거 문장
- [ ] 노드 클릭 → 독(dock) 패널: 프로젝트 요약·기록·연결된 프로젝트
- [ ] **연결 노트**: 그래프에서 노트 작성, 여러 프로젝트에 연결
- [ ] 진학/취업 선택 → 학과/직무 후보(넓이 0.5 + 깊이 0.5, "연결도 %") → 근거 프로젝트(점선) → 문장까지 추적
- [ ] 학과 → 개설 대학, 직무 → 공고/준비 정보 (프로토타입의 postings 영역; 데이터가 없으면 정직한 빈 상태)
- [ ] ✦ 추천 근거 설명(AI, 근거 문장만 읽음)
- [ ] 화면 문구에 "관련성 탐색, 합격 가능성 아님" 유지

### ③ 포트폴리오 (발표 p19~20, 프로토타입 `#/portfolio/1~3`)
- [ ] 1 서식 선택(프로젝트 포트폴리오 / 학생부 대체서식) · 2 프로젝트 선택·순서 변경 · 3 편집
- [ ] ✦ 근거 문장만으로 초안, 문장마다 "참고한 기록" 표시, 원문에 없는 성과 검출·차단
- [ ] 문장 다듬기(더 간결하게 / 내 역할 중심) + 수정 전후 비교(diff)
- [ ] 프로필·자기소개, 초안과 학생 수정본 분리 저장, 미리보기·인쇄/PDF

### ④ 스크랩 (발표 p17, 프로토타입 `#/scraps`)
- [ ] 학과·대학·직무·공고·노드 스크랩, 메모, 할 일 체크리스트, 클릭 시 보던 그래프 위치로 복귀

### 데이터
- [ ] 점수표·대학 목록: `zz_local/profiles.csv`·점수표 자료를 DB 시드로 넣는 스크립트. 부족하면 커리어넷 등 공개 자료로 보강하되 출처·수집일 기록
- [ ] 시드 학생(김서윤) + 실제 거캠 기록으로 전체 흐름이 끝까지 이어지는지 확인

## 2단계 — 그 이상의 편의성 (1단계가 끝나면 스스로 찾아서 계속)

예시이며, 이 목록에 묶이지 말고 실제 화면을 써 보며 학생이 막히는 곳을 찾아 고친다.
- 첫 사용자 온보딩: 빈 계정에서 "거캠 기록 한 번 올리기"로 바로 가는 길, 시드 데모 계정
- 끌어다 놓기 업로드, 여러 파일 한 번에, 진행 중 이탈해도 이어하기
- "다음에 하면 좋은 것" 한 곳에 모아 보기 (보완 질문·빠진 증빙·포트폴리오 준비)
- 키보드 단축키, 자동 저장 표시, 실행 취소
- 그래프: 필터(태그·기간), 검색으로 노드 이동, 확대 상태 기억
- 포트폴리오: 서식별 글자 수 제한 표시, 대학 제출 형식 체크리스트
- 성능: 큰 PDF, 프로젝트 많을 때 그래프, 첫 화면 로딩
- 접근성: 대비, 포커스, 스크린리더 라벨
- 오류 메시지를 학생 말투로, 실패 시 입력 보존

각 개선은 "어떤 학생이 어떤 순간에 무엇이 불편했나"를 결정 기록에 쓰고 시작한다.
